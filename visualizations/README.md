# Generated visualizations

The notebook and `src/train_model.py` generate charts here after retrieving the official UCI dataset.

Expected outputs include:
- `target_distribution_real_data.png`
- `feature_distributions_real_data.png`
- `correlation_heatmap_real_data.png`
- `confusion_matrix_logistic_regression_real_data.png`
- `confusion_matrix_random_forest_real_data.png`
- `roc_curves_real_data.png`

These files are generated by running the notebook or script. They are not committed as precomputed findings, so the visualizations should always correspond to the code and data version used in the run.

Dataset: UCI Machine Learning Repository, [Default of Credit Card Clients](https://archive.ics.uci.edu/dataset/350/defaultofcreditcardclients), DOI [10.24432/C55S3H]. Historical data from Taiwan (2005); educational use only.
